# E5 items (museum humidity monitoring)

Finding: The principal finding is that readings at the northeast corner rose by 14 percent relative humidity during the four nights following each weekly deep-clean, when the building's dehumidifier was switched off for maintenance.

Evidence limit: The sensors were calibrated against a reference hygrometer before deployment, but the reference unit itself was only checked once, which means absolute values may sit a point or two off even though the relative pattern holds.

Scope limit: The study covered a single annex with one ventilation layout, so the same cleaning-related swing may not appear in galleries with different construction, occupancy, or climate control.

Condition before acting: Before anyone adjusts the cleaning schedule or the dehumidifier timing, the team should confirm that the reference hygrometer has been recalibrated against a traceable standard, since any shift in that instrument would change the size of the effect the note reports.
